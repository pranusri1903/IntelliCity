Dijkstra's Algorithm — Shortest Path
Finds the optimal route between two junctions considering both road distance and congestion penalty. Effective cost = distance + (congestion × 50).
Complexity: O((V+E) log V)
Result
Select source and destination to compute shortest path.
BFS — Alternate Route Detection
Finds the route with fewest hops (unweighted). Useful for detecting alternate paths during congestion bypass.
Complexity: O(V+E)
Result
Select junctions to find BFS route.
Floyd-Warshall — All-Pairs Shortest Paths
Computes shortest paths between every pair of junctions. Used for city-wide navigation planning.
Complexity: O(V³)
DFS — Network Traversal
Performs depth-first traversal from a starting junction. Used for connectivity checking across the city network.
Complexity: O(V+E)
Traversal Order
Select start junction.
Kruskal's MST — Optimal Infrastructure Planning
Sorts every road by physical distance and greedily accepts the cheapest ones that don't close a cycle, tracked with a disjoint-set (union-find) structure. The result is the minimum total road length needed to keep all 15 junctions connected — a lower bound on how much infrastructure the city actually needs to build.
Complexity: O(E log E)
